### About ###
Basic tornadoweb example slapped together in a few minutes

### Usage ###
* Drop Andrew Valums fileuploader.css and fileuploader.js into the same directory you got file-uploader.py in
* Create an 'upload' directory
* Run file-uploader.py and point your browser to http://localhost:8888
